# ROKFOSS-Shield 커스텀 오토인덱스

nginx 내장 `autoindex` 의 출력 화면 자체를 우리 커스텀 화면으로 바꾼 기능이다.
`autoindex on;` 만 켜면 별도 설정 없이 커스텀 화면이 나온다.

## 왜 만들었나

fancyindex 로 미러 디렉터리를 열면 브라우저가 멈추는 문제가 있었다. 항목이
7,000 개인 디렉터리에서 다음이 벌어졌다.

1. 서버가 7,000 행짜리 HTML 표를 만들어 보낸다.
2. 브라우저가 7,000 행을 DOM 으로 만들고 배치까지 계산한다.
3. 스크립트가 그 표를 다시 읽어 재구성한다.

같은 일을 두 번 하고, 화면에 보이지도 않을 행을 전부 그린다. 여기에 헤더/푸터
보일러플레이트가 매 디렉터리마다 따라붙었다.

## 어떻게 바꿨나

내장 autoindex 모듈(`ngx_http_autoindex_module`)의 HTML 출력 함수를 교체했다.

- **디렉터리 읽기는 검증된 nginx 코어 코드를 그대로 쓴다.** 우리는 출력 형식만
  바꾼다. 파일 시스템을 직접 훑는 코드를 새로 만들지 않는다.
- **행 HTML 을 보내지 않는다.** 항목 데이터를 JSON 으로 한 번 실어 보내고,
  브라우저는 화면에 보이는 약 30 행만 그린다(가상 스크롤). 항목이 7,000 개든
  10 만 개든 DOM 노드 수가 일정해서 멈추지 않는다.
- **CSS/JS 는 페이지에 인라인**되어 자족적으로 동작한다. 별도 정적 파일이나
  location 설정이 필요 없다.

## 설정

```nginx
location / {
    autoindex on;
}
```

이게 전부다. `autoindex on;` 이 켜진 디렉터리에서 커스텀 화면이 나온다.

`autoindex_format json` / `xml` 을 지정하면 종전대로 기계용 출력이 나온다.
커스텀 화면은 기본값(html)일 때만 적용된다.

## 기능

- 즉시 검색 (`/` 키로 검색창 진입, `Esc` 로 해제, 일치 부분 강조)
- 이름·크기·수정일 정렬 (디렉터리는 항상 위)
- 경로 빵부스러기(현재 URL 에서 생성), 파일 종류 아이콘
- 다크/라이트 자동 전환, 모바일 대응

## 안전성

파일명은 동기화로 들어오는 신뢰할 수 없는 값으로 다룬다. 목록 JSON 을 만들 때
`"` `\` 제어문자와 함께 `<` `>` 도 `<` `>` 로 이스케이프한다. 파일명에
`</script>` 가 들어 있어도 HTML 파서가 스크립트를 끊지 못한다.

버퍼 크기 계산은 ASAN(주소 새니타이저) 빌드로 7,203 개 항목 및 특수 파일명
디렉터리에 대해 heap overflow 가 없음을 확인했다.

## 화면 코드 수정 방법

CSS/JS/골격은 `util/rokfoss-autoindex-src/` 에 원본이 있다.

```text
util/rokfoss-autoindex-src/
    idx.css      스타일
    idx.js       가상 스크롤·검색·정렬
    head.html    페이지 골격 앞부분(<script id="idx-data"> 까지)
    tail.html    골격 뒷부분
    gen.py       위를 C 헤더로 변환
```

화면을 고치려면 `idx.css` / `idx.js` 등을 수정한 뒤 `gen.py` 를 실행해
`ngx_http_rokfoss_autoindex.h` 를 다시 만들고, 그 헤더를
`nginx-<ver>-rokfoss_autoindex.patch` 에 반영한다. C 문자열은 손으로
이스케이프하지 않는다. `gen.py` 가 바이트 단위로 처리한다.

## 주의

- `autoindex on;` 을 켠 곳에만 적용된다. 색인 파일(`index.html` 등)이 있으면
  그 파일이 우선한다.
- CSS/JS 가 페이지당 약 10KB 인라인된다. 정적이라 gzip 으로 잘 압축되고, 항목이
  많은 디렉터리에서는 목록 데이터가 훨씬 크므로 무시할 수준이다.
